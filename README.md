# Projeto Integrador

Aplicativo de apoio pessoal para organizar notas e contatos de confiança e enviar solicitações SOS. O painel permite acompanhar os chamados e administrar usuários.

## Iniciar

Execute `stater.cmd` na raiz do projeto. Ele inicia o Expo e a API simultaneamente no mesmo console e mantém a janela aberta com `pause`.
